## A. MVP 시나리오

전제: 모바일 웹 WebAR(PRD 6장), 로그인 직후 풀스크린 AR 뷰 + 하단 중앙 FAB(PRD 7장). 공개 무료·브론즈 캡슐, 사진만 지원(PRD 3.1).

### SC-01 회원가입·로그인

맥락: 기념일에 추억을 남기려는 커플 중 한 명이 처음 접속한다.

| 항목 | 내용 |
|---|---|
| 액터 | 뷰어·크리에이터 |
| 사전 조건 | HTTPS로 접속(NFR-07) |
| 결과 | 세션 토큰을 HttpOnly 쿠키로 발급(유효 기간 M-04), AR 뷰(SC-02)로 이동 |
| 관련 ID | FR-01, BR-01, Q-05, M-04, M-05 |

주요 흐름
1. 이메일·비밀번호로 가입한다.
2. 로그인하면 세션 토큰을 HttpOnly 쿠키로 받는다 (FR-01).
3. 바로 AR 뷰 진입 단계(SC-02)로 넘어간다.

예외 흐름

| 조건 | 처리 |
|---|---|
| 비로그인 상태로 API 호출 | 가입·로그인·헬스 체크 외 모든 API 401 (FR-01, BR-01) |
| 이메일 중복 가입 | 409 (FR-01) |
| 비밀번호 불일치 | 계정 존재 여부를 드러내지 않는 메시지로 401. 연속 실패가 M-05를 넘으면 잠금, 429 (FR-01) |
| 세션 만료·로그아웃 | 다시 로그인. 로그아웃하면 DB에서 세션 삭제 (FR-01) |
| 비밀번호 분실 | MVP에서 재설정 불가 (PRD 3.2) |

### SC-02 권한 허용과 AR 뷰 진입

| 항목 | 내용 |
|---|---|
| 액터 | 뷰어·크리에이터 |
| 사전 조건 | 로그인 완료 |
| 결과 | 카메라 AR 뷰와 FAB 표시, 주변 조회(SC-04) 시작 |
| 관련 ID | FR-02, Q-12, PRD 7장 |

주요 흐름
1. 첫 화면에서 "시작"을 누른다 (iOS는 이 탭으로 방향 센서 권한 요청, Q-12).
2. 카메라·위치·방향 센서 권한을 모두 허용한다 (세 권한 모두 필수, FR-02).
3. 풀스크린 AR 뷰와 FAB가 나타난다.

예외 흐름

| 조건 | 처리 |
|---|---|
| 카메라·위치·방향 센서 중 하나라도 거부 | AR 뷰 대신 권한 안내 화면과 재시도 버튼 (FR-02) |

### SC-03 기념 장소에 사진 캡슐 드롭

맥락: 커플이 프러포즈한 장소에 사진을 남긴다.

| 항목 | 내용 |
|---|---|
| 액터 | 크리에이터 |
| 사전 조건 | SC-02 완료, 현장에 있음 |
| 결과 | 캡슐 Active, `expires_at` 계산됨 (FR-07, 도메인 5.1, PRM-06) |
| 관련 ID | FR-03, FR-04, FR-06, FR-07, BR-04(대체, Q-02), BR-05(완화, Q-10), BR-10, BR-33, PRM-03, PRM-20, Q-04, Q-13, Q-14, M-06~09, M-13 |

주요 흐름
1. FAB → "여기에 드롭"을 고른다.
2. 사진 1장을 고르거나 촬영한다 (FR-04, Q-10).
3. AR 화면에 고른 사진을 담은 미리보기 프레임이 뜬다. 프레임을 끌어 위치를 정하고, 회전 슬라이더로 프레임 방향을 정한 뒤 "여기에 놓기"를 누른다. 프레임은 내 위치에서 드롭 배치 반경(PRM-20) 밖으로 나가지 않는다 (FR-03, Q-13, Q-14).
4. 정한 위치의 GPS 좌표·프레임 방향과 그 순간 내 GPS 좌표·정확도를 앵커로 캡처한다 (FR-03). 캡슐 행은 아직 만들지 않는다 (FR-06).
5. 제목을 입력한다. 등급 입력 단계는 없고 브론즈로 고정된다 (FR-07, PRD 7장).
6. 브라우저가 사진을 JPEG로 재인코딩(M-13)하고 썸네일(M-07)을 만들어, 원본과 함께 Presigned URL로 S3에 직접 업로드한다. 객체에는 `status=pending` 태그가 붙는다 (FR-04).
7. 앵커·제목·미디어 키를 한 번에 게시 요청한다. 검열을 통과하면 태그를 지우고 캡슐 행이 Active로 만들어진다. 결제는 없다 (FR-06, FR-07).
8. 완료 표시. 바텀시트는 최대 4단계다 (PRD 7장).

예외 흐름

| 조건 | 처리 |
|---|---|
| GPS 정확도가 재측정 기준(PRM-03)보다 나쁨 | 드롭 차단, 재측정 안내 (FR-03) |
| 게시 요청의 앵커가 내 위치에서 PRM-20보다 멂 (위치를 정한 뒤 많이 걸어간 경우 등) | 서버가 422 `DROP_TOO_FAR`로 거부, 위치를 다시 정하라고 안내 (FR-03) |
| 허용 형식·크기 위반 | 사진 선택 시 브라우저가 먼저 막고, 서버에서도 재검증해 거부 (FR-04) |
| 검열 거부 | 캡슐 행을 만들지 않고 S3 객체 삭제, 사유 안내. FAB에서 새로 시작 (FR-06, 도메인 6.2) |
| 브론즈 외 등급 요청 | 서버가 거부 (FR-07) |
| 업로드 도중 이탈·실패 | 캡슐 행이 없으므로 남는 데이터가 없다. 태그가 남은 S3 객체는 수명 주기 규칙이 M-08 뒤 삭제 (FR-04, PRD 3.2) |
| 검열 API 실패·제한 시간(M-09) 초과 | 캡슐 행을 만들지 않고 503, "다시 시도" 안내. 업로드한 객체로 재요청 (FR-06) |

### SC-04 주변 캡슐 탐색

맥락: 러닝 동호인이 코스를 달리며 주변 캡슐을 찾는다.

| 항목 | 내용 |
|---|---|
| 액터 | 뷰어 |
| 사전 조건 | SC-02 완료 |
| 결과 | 주변 Active·미만료 캡슐이 AR 프레임으로 표시됨 |
| 관련 ID | FR-08, FR-09, BR-11, BR-26(지도 탭 제외, Q-06), NFR-06, PRD 7장 |

주요 흐름
1. AR 뷰가 현재 위치 기준 조회 반경(M-01)의 캡슐 목록(썸네일만, NFR-06)을 받는다.
2. 캡슐이 3D 프레임으로 표시된다 (FR-09).
3. 열람 가능(반경 안)/불가(반경 밖) 프레임이 색·투명도로 구분되고, 반경 밖은 남은 거리가 표시된다 (PRD 7장).
4. 이동하면 최소 간격(M-02)으로 목록이 갱신된다. FAB → "주변 스캔"으로 수동 갱신도 할 수 있다.

예외 흐름

| 조건 | 처리 |
|---|---|
| GPS 정확도가 재측정 기준(PRM-03)보다 나쁨 | 상단 경고 배너, 드롭·열람 차단 (PRD 7장) |
| 만료·미검열 캡슐 | 목록에서 제외 (BR-11, FR-06) |

### SC-05 반경 안 캡슐 열람

맥락: 동호인이 다른 회원이 반환점에 남긴 인증 사진을 연다.

| 항목 | 내용 |
|---|---|
| 액터 | 뷰어 |
| 사전 조건 | SC-04에서 캡슐 프레임이 보임 |
| 결과 | 원본 사진 표시, ViewRecord 저장 |
| 관련 ID | FR-10, BR-27, 도메인 5.4(GPS 판정만), PRM-01, PRM-03, Q-03, Q-11, NFR-05, NFR-08 |

주요 흐름
1. 프레임을 터치한다.
2. 서버가 도메인 5.4 판정식(PRM-01, PRM-03)으로 거리를 판정한다 (FR-10).
3. 통과하면 원본 경로(`/api/media/:mediaId`)를 받아 사진을 보여 주고, 열람 기록을 저장한다. 증명 ID 컬럼은 두지 않고 뷰어 좌표·정확도·IP 해시(HMAC)를 함께 남긴다 (FR-10, INV-06).
4. 같은 사진을 다시 열면 브라우저 캐시에서 표시된다 (NFR-05).

예외 흐름

| 조건 | 처리 |
|---|---|
| 반경 밖 | 거부하고 남은 거리 안내 (FR-10, BR-27, NFR-08) |
| GPS 정확도가 재측정 기준(PRM-03)보다 나쁨 | 판정하지 않고 재측정 안내 (FR-10) |
| 목록 수신 후 캡슐이 만료·삭제됨 | 서버 판정으로 404, "더 이상 볼 수 없는 캡슐이에요" 안내 후 주변 재조회 (FR-10, NFR-08, BR-11) |
| GPS 스푸핑 | MVP는 수용 (Q-11) |

## B. 후속 단계 시나리오

전제: 네이티브 앱(`10-native-PRD.md`)으로 전환한 뒤 도메인 규칙을 그대로 적용한다 (Q-01, FR-12). 현장 증명은 도메인 5.4 전체 판정(평면 일치, PRM-04, PRM-05, 무결성)을 쓴다 (Q-11).

### SC-08 등급 결제 후 드롭 (유료 체크포인트 포함)

맥락: 피트니스 인플루언서가 헬스장 기구 앞에 운동 팁을 유료 체크포인트로 남긴다.

| 항목 | 내용 |
|---|---|
| 액터 | 크리에이터 |
| 사전 조건 | 가입·로그인(BR-01~03), 현장에 있음 |
| 결과 | 캡슐 Active, Purchase(DROP_FEE) VERIFIED 또는 무상 크리스탈 차감 |
| 관련 ID | INV-02~04, BR-04~10, BR-12~14, BR-33, BR-40, 도메인 5.1·5.2·5.4, IAP-01~03, IAP-07, PRM-10, PRM-11 |

주요 흐름
1. 평면 스캔으로 프레임을 앵커링하고 현장 증명(DROP)을 받는다 (BR-04, 5.4).
2. 갤러리 미디어를 붙인다 (BR-05).
3. 공개 캡슐이면 열람가를 5.2에서 고른다 (BR-12). 고르지 않으면 무료 캡슐이다.
4. 등급을 고른다 (BR-06, 5.1).
5. AI 사전 검열을 통과한다 (BR-10, BR-33).
6. 인앱결제로 등록비를 내고, 서버가 영수증을 검증하면 게시된다 (BR-07, BR-09).

대안 흐름: 브론즈는 무상 크리스탈(PRM-11)로 등록한다 (BR-08). 부족하면 보상형 광고(PRM-10)로 모은다.

예외 흐름

| 조건 | 처리 |
|---|---|
| 현장 증명 SUSPICIOUS·만료·재사용 | 드롭 거부 (BR-40) |
| 검열 거부 | Rejected, 결제 없음 (도메인 6.2) |
| 영수증 검증 실패 | Purchase FAILED, 게시 안 됨, 스토어 환불 요청 안내 (6.3, IAP-07) |
| 결제 후 서버 검증 전 앱 종료·네트워크 끊김 | 스토어 거래를 완료 처리하지 않았으므로 앱 재실행 시 서버로 다시 보내고, 스토어 서버 알림으로도 확인 (IAP-07) |
| 같은 거래 재전송 | 1회만 처리 (BR-09, INV-04) |
| 실버·마스터를 무상 크리스탈로 등록 시도 | 불가 (BR-08) |
| 광고 하루 한도 도달 | 추가 보상 없음 (PRM-10) |
| 결제하지 않고 이탈 | PRM-16 경과 후 Discarded (6.2) |
| 게시 후 열람가 변경 시도 | 불가, 새로 등록 (BR-14) |
| 등록비 스토어 환불 | 캡슐 Deleted, 유료 체크포인트면 BR-20 (BR-38, SC-16) |

### SC-09 유료 체크포인트 구매·열람

맥락: 러닝 동호인이 트레이너의 유료 체크포인트를 현장에서 산다.

| 항목 | 내용 |
|---|---|
| 액터 | 뷰어 |
| 사전 조건 | 유료 체크포인트 Active, 뷰어가 소유자가 아님 |
| 결과 | Entitlement 부여, 크리에이터 판매 수익 적립(보류) |
| 관련 ID | 도메인 6.1, INV-03~05, BR-15~18, BR-21, BR-27, BR-30, BR-40, ST-01, ST-04, IAP-07, PRM-01, PRM-12, PRM-13 |

주요 흐름
1. 지도에서 미리보기를 본다 (BR-15).
2. 열람 반경(PRM-01) 안으로 가서 현장 증명을 받는다 (BR-16, 5.4).
3. 열람권이 없으면 남은 유지 기간 안내 후 인앱결제한다 (6.1).
4. 서버가 영수증을 검증하면 열람권이 생긴다 (BR-09, INV-05).
5. 크리에이터에게 판매 수익(ST-01, PRM-12)이 보류 상태로 적립된다 (PRM-13).
6. 새 현장 증명(OPEN)을 받아 열람한다. 결제에 쓴 증명은 열람에 쓸 수 없다 (BR-40, 6.1). 캡처·녹화 차단과 워터마크가 적용된다 (BR-21).
7. 이후 재방문 때마다 현장 증명을 통과하면 다시 열람한다 (BR-18).

예외 흐름

| 조건 | 처리 |
|---|---|
| 반경 밖에서 결제 시도 | 불가 (BR-16) |
| 현장 증명 SUSPICIOUS·만료·재사용 | 결제·열람 거부 (BR-40) |
| 소유자가 구매 시도 | 불가, 결제 없이 열람 (BR-17, INV-04) |
| 결제 증명으로 바로 열람 시도 | 거부, 새 증명 필요 (BR-40) |
| 스토어 결제 성공 후 서버 검증 전 앱 종료 | 앱 재실행 시 미완료 거래를 다시 보내 검증 (IAP-07) |
| 캡슐 Blinded | 열람권 유지, 열람 불가 (INV-05, 6.2) |
| 캡슐 Expired·Removed·Deleted | 열람권 종료 (INV-05) |
