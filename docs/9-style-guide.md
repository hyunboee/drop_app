## 1. 디자인 방향

- **분위기:** 해 질 녘 빛이 비스듬히 드는 흙, 그 속에 묻힌 금속 캡슐. 어두운 바탕 위에 **금(골드)과 아이보리**만 빛나게 쓴다.
- **원칙**
  - 화면의 주인공은 카메라 영상(W-05)이나 배경 사진(W-01·W-02)이다. UI는 얇고 낮게 깔고, 면(카드·박스)을 최소로 쓴다.
  - 강조는 금색 한 가지. 한 화면에 금색 채움 요소(주요 버튼)는 하나만 둔다.
  - 입력란은 상자 대신 **밑줄**, 버튼은 **각진 직사각형**(모서리 둥글림 없음). 둥근 형태는 FAB와 바텀시트 윗모서리만 쓴다.
  - 제목·라벨은 넓은 자간으로 고요하게, 본문은 기본 자간으로 읽기 쉽게.

## 4. 컴포넌트 규칙

### 4.1 버튼

| 종류 | 모양 | 상태 | 화면 |
|---|---|---|---|
| **주요(primary)** | 높이 50px, 폭은 좌우 `--space-gutter` 안을 꽉 채움, `--gradient-gold` 채움, 글자 `--type-button` `--color-text-on-gold`, 모서리 `--radius-none` | **기본** 위와 같음 · **누름** `filter: brightness(0.92)` · **비활성** `opacity: 0.4`, 누름 반응 없음 · **전송 중** 비활성과 같은 모양 + 글자 자리에 점 세 개가 차례로 깜빡임, 연속 탭 막음 | W-01 로그인, W-02 가입하기, W-03 시작, W-04 재시도, W-07 다음, W-08 드롭하기, W-09 다시 시도, W-10 확인 |
| **보조(secondary)** | 주요와 같은 크기, 바탕 투명, 테두리 1px `--color-gold-500`, 글자 `--color-gold-300` | 비활성·전송 중은 주요와 같은 규칙 | W-08 ‹ 이전, W-09 취소·사진 다시 선택, W-12 닫기 |
| **텍스트(text)** | 높이 없이 글자만, `--type-link`, `--color-text` + 밑줄(일반) / `--color-error`(되돌릴 수 없는 동작) | 누름 `opacity: 0.7` | W-01 가입하기, W-02 ‹ 로그인, W-06 로그아웃, W-11 삭제(오류 색) |

- 한 화면에 주요 버튼은 하나만 둔다. 둘이 필요하면 하나를 보조로 내린다(W-08, W-09).
- 삭제처럼 되돌릴 수 없는 동작은 텍스트 버튼 + `--color-error`로 두고, 누르면 브라우저 기본 확인창을 띄운다(FR-11, W-11).

### 4.2 입력란·체크박스

| 요소 | 규칙 | 화면 |

| 오류 문구 | 밑줄 아래 `--space-3`, `--type-caption` `--color-error`. 문구는 문서에 정한 그대로(FR-01 등) | W-01, W-02, W-07, W-09 |
| 글자 수 | 라벨 오른쪽 끝 `--type-label` `--color-text-muted` "0/40"(M-11) | W-08 |
| 체크박스 | 16px 정사각형, 테두리 1px `--color-gold-500`, 체크 시 `--color-gold-500` 채움 + `--color-text-on-gold` 체크 표시. 글자 `--type-caption` `--color-text-sub`, 오른쪽 끝에 "전문 보기" 텍스트 버튼 | W-02 |

| 뒤 배경 | 카메라 영상 위에 `--color-scrim` | W-07~W-10 |

### 4.4 배너·상태 한 줄·안내

| 요소 | 규칙 | 화면 |
|---|---|---|
| **정확도 경고 배너** | 화면 맨 위(상태바 아래)에 폭 전체, 높이 40px. `--color-warning-bg` + `--blur-glass`, 왼쪽 경고 아이콘과 글자 `--type-caption` `--color-warning`. 정확도가 재측정 기준(PRM-03)보다 나쁠 때만 나타나고, 회복되면 위로 사라진다. 닫기 버튼 없음 | W-05 ① |

| **권한 안내 화면** | 흐린 사진 배경 위 가운데 정렬. 제목 `--type-title`, 권한 목록은 `--type-body` + 앞에 금색 점, 안내 `--type-caption` `--color-text-sub`, 맨 아래 주요 버튼 | W-03, W-04 |

## 6. 하지 않는 것

- 웹폰트, 아이콘 폰트, UI 라이브러리를 새로 넣지 않는다. 아이콘(+, ×, 체크, 경고, 위치 핀)은 인라인 SVG로 직접 그린다.
- 금색 채움 버튼을 한 화면에 두 개 이상 두지 않는다.
- 카드·그림자 박스로 화면을 나누지 않는다(바텀시트·안내 박스·배너만 예외).
- 다크/라이트 전환은 두지 않는다. Drop은 어두운 화면 하나만 쓴다.
